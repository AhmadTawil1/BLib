# BLib Project

This project consists of a client-server library management system. It includes:

- **BLibClient**: A JavaFX-based client application for managing library operations.
- **BlibServer**: A server application that handles client requests and database operations.
- **BlibCommon**: Shared code (models and enums) used by both client and server.

## Project Structure

- `PROJECT/G3_Assignment3-Project/`
  - `BLibClient/`: Client-side application
  - `BlibServer/`: Server-side application
  - `BlibCommon/`: Shared code
